Release Notes — 13.7.0-0.1.0

This is the initial alpha release of BudgetGamers Debian Edition. Based on Debian 13.7.0 (Trixie) with KDE Plasma. Pre-installed gaming utilities, custom branding, and an optimized out-of-the-box experience. Expect rough edges — feedback is welcome!

View the full changelog for complete details.

System Requirements

Minimum

  • OS: 64-bit
  • Processor: Early Ryzen or Intel Equivalent
  • Memory: 4GB RAM
  • Graphics: Integrated Graphics
  • Storage: 32GB HDD available space

Recommended

  • OS: 64-bit
  • Processor: Ryzen 3000 or Intel 7th gen equivalent
  • Memory: 16GB RAM
  • Graphics: Dedicated Graphics Card
  • Storage: 256GB SSD available space

* Hardware Requirements are subject to user preference.
